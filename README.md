# derickjanssen.com — v1

A fast, dark, game-y portfolio for Derick Janssen. It's plain static HTML/CSS/JS generated by a **zero-dependency** Node script, so there's no framework, no `npm install`, and no 3D/WebGL. It also ships **Bug Hunt**, a persistent mini clicker game.

## Project goals

This site should feel like a small game, not a brochure.

- Stay **dark and gamey**. High contrast on a near-black field, accent green / cyan / pink / gold, chunky type, no airy SaaS-white layouts.
- Punchy, **juiced 2D** animation and transitions: hit-stop, squash and stretch, springy easing, particles, screen shake, and impact flashes. Motion should sell every click, spawn, kill, and page change.
- **Smooth 60fps** on tablet and phone, including a Samsung Galaxy Tab S8 Ultra. Budget particles and effects so the frame rate stays up; drop effect density before you drop frames.
- **No heavy 3D.** No WebGL scenes, no model viewers, no post-process stacks. Canvas 2D, CSS, and baked images are the toolbox.
- Respect **`prefers-reduced-motion`** and the game’s **adaptive quality** (quality tiers 0–3). Big juice is the default; a calmer, still-readable version is required.

## Juice standards

Every visual or gameplay change should keep this checklist true:

- [ ] The action has a readable anticipation, impact, and settle (not a linear teleport).
- [ ] Hits use a short **hit-stop** plus **squash/stretch** on the thing that got hit or launched.
- [ ] Impacts kick up **particles** and a brief **flash**; bigger moments also **shake** the screen.
- [ ] Easing is springy (`--spring` / `--snap`), not ease-linear fades that feel like a PowerPoint.
- [ ] Effect counts and blur scale with the quality tier; `prefers-reduced-motion` skips shake, long flashes, extra particles, and hit-stop while keeping state changes readable.
- [ ] The change still holds ~60fps on tablet/mobile (Tab S8 Ultra class). If it cannot, cut particles or flash size, not the frame rate.
- [ ] Nothing introduces heavy 3D or a new runtime. Keep it 2D canvas / CSS.
- [ ] New work should feel *more* alive than a static mock, not less.

```
data/projects.json      ← ALL site content (edit this)
static/css/site.css     ← all styles (inlined into each page at build time)
static/js/main.js       ← reveals, YouTube facades, page transitions, lazy-loads the game
static/js/game.js       ← Bug Hunt clicker/idle game
static/img/*.webp       ← optimized images (generated)
tools/optimize_images.py← source images → resized WebP (needs Python + Pillow)
build.mjs               ← builds dist/ (home + one page per project + 404)
```

The outlined **JANSSEN** in the hero is a baked SVG path (Inter 900 with overlapping variable-font contours **unioned** so the A is a single outer silhouette plus one inner triangle, not overlapping stems plus a separate crossbar). It is not live text, so it cannot pick up a fallback font or a bad `getComputedTextLength()` and overlap or overflow on phones. It is sized to `5.4em` of the title (max 100%) and clamped to the container in both portrait and landscape.

Each build stamps JS URLs with a content hash (`js/main.js?v=<hash>`, and `main.js` loads `js/game.js?v=<hash>` via a `data-game` attribute) so phones fetch new scripts without a manual cache clear. CSS is inlined, so it updates whenever the HTML document does; a `asset-rev` meta tag records the CSS/JS hashes.

## Run locally

```bash
node build.mjs                 # build to dist/ (TODO notes visible)
cd dist && python3 -m http.server 8080   # open http://localhost:8080
```

`node build.mjs --hide-todos` strips the orange `TODO:` notes. CI uses this for production.

## Editing content

Everything lives in **`data/projects.json`**:

- `site`: name, title, tagline, email, links, hero stats.
- `projects[]`: one entry per project. `group` sets the section: `featured` (big cards), `earlier`, or `lab` (tech/AI/side).
  - `slug` is the URL (`/projects/<slug>/`). Set `"noPage": true` for a card with no detail page.
  - `image` / `cardImage` / `gallery[]` take image **keys** (see below). `youtube` takes a video id, and it loads only when clicked.
  - `summary`, `bullets[]`, `tags[]`, `awards[]`, `links[]`, `todo[]`.
- `jams[]`, `awards[]`, `experience[]`, `education[]`, `skills`, `talks[]`, `about[]`, `gaming[]`.

Order in the JSON = order on the page. Rebuild after editing.

### Adding an image

1. Put the source file somewhere (any size, png/jpg).
2. Add a line to `IMAGES` in `tools/optimize_images.py`: `'my-key': ('path/to/file.png', [480, 960])`.
3. Run `python3 tools/optimize_images.py /path/to/source/root` (needs `pip install pillow`). This writes `static/img/my-key-<w>.webp` and updates `images.json`.
4. Use `"image": "my-key"` in `projects.json` and rebuild.

(If you only have one ready-made WebP, drop it in `static/img/` as `my-key-<width>.webp` and add `"my-key": {"w": [<width>], "ratio": <w/h>}` to `static/img/images.json`.)

## Bug Hunt — Game Design

Numbers below are taken from `static/js/game.js` as implemented. Costs are in **Commits** and are rounded up (`Math.ceil`). Buying **Rapid Prototype** multiplies every shop price by **0.78** (~22% off).

### Juice (design rule)

Bug Hunt is a juiced 2D game inside the site, not a utility overlay. Kills, pulses, missiles, promotions, and shop unlocks should hit with squash/stretch, hit-stop, particles, a flash, and a shake, then settle. Respect `prefers-reduced-motion` and the adaptive quality tier: drop the extra motion before you drop the frame rate. Same standards as the top-level **Juice standards** checklist.

### Opt-in

The game does not run until you press **Play Bug Hunt** (bottom-right). Before that there are no bugs, no LOC, and clicks on the page behave normally. Pause or quit shows **Resume Bug Hunt**; progress is kept. A first-run hint says to click/tap empty space to write code. **Pause** freezes the sim and leaves you where you were (including Play Space). **✕** (quit) also saves progress, but if you were in Play Space it exits that overlay first so the normal site chrome and scroll position come back. There is never a state where the site is hidden and you have no way back: the HUD **Site** button, and the Resume button when paused, stay above the playfield.

### Play Space

After **25** player actions since opt-in — empty-space clicks that write LOC, plus click-squashes (laser, QA, and idle kills do not count) — you are promoted to **Play Space**: a full-screen blank playfield (dark background, game canvases, HUD) so site links cannot steal taps. Derick’s name (the DERICK JANSSEN wordmark) stays on screen but is not a link and uses `pointer-events: none`. A short juiced banner reads **Promoted: Play Space unlocked**. The HUD gains a **Play Space** / **Site** button so you can return to the portfolio and come back; the mode is stored on the save as `playSpace`, `playUnlocked`, and `clicks`. This is an overlay on the current page (not a navigation), so game state is preserved and it works under the `/portfolio-site/` preview path.

**Quit vs pause vs resume.** ✕ while Play Space is on sets `playSpace` false, restores site chrome and the scroll position saved when you entered, then pauses and saves as usual. Pause does not touch `playSpace`. **Resume Bug Hunt** (`optIn`) calls `applyPlaySpace()` against whatever `playSpace` currently is: after a quit you land back on the site; after a pause inside Play Space you return to Play Space (if it is still unlocked). Clicking **Ship** also force-enters Play Space (and unlocks it if needed) so the finale has room.

### Core loop

1. Click or tap **empty page space** to write **+1 LOC** and hatch a bug near the cursor. Dim hacker-typer code paints across the background as you write.
2. Click a normal bug to squash it. Tier 2–3 bugs **split** into two of the next-smaller tier (if there is room under the entity cap). Tier 1 bugs splat.
3. Squashes pay **Commits**, which buy upgrades. After **5 squashes** the shop opens with **Hire Derick** as the first unlock.
4. Derick and agents automatically laser bugs. Each of them drafts extra LOC independently whenever that unit has no target in range (they are not lasering) — not after a global “board is clear” wait.

### Currencies

| Currency | What it is | How you earn it |
| --- | --- | --- |
| **LOC** | Lines of code written this run (the build counter) | Empty-space clicks (+1), idle drafting by Derick/agents, and a little offline catch-up |
| **Commits** | Shop currency | Squashing bugs. A normal bug pays `tier × 3`; a boss pays **18**. QA-targeted bugs pay **1.25×**. Each prestige/Ship rank adds a permanent **+50%** bounty: `mult = 1 + (prestige || ships) × 0.5` |

Bugs per LOC starts at **0.38**, then `× 0.82` per Unit Tests rank (max 5) and `× 0.85` if CI is owned. Click-hatches apply that rate in full; automatic/idle LOC applies it more slowly (32% for leftover debt, **`IDLE_DEBT` 0.045** for idle drafts) so the higher idle rates do not instantly refill the board.

### Bugs: spawn, split, merge

- Nothing spawns until you opt in **and** click empty space (or later idle/QA/debt sources kick in).
- A click-hatch picks a tier: chance of tier 3 is `min(0.5, 0.1 + loc/3000)`; otherwise 70% tier 2 / 30% tier 1.
- **Cap:** 8 live bugs on coarse pointers or viewports under 700px, otherwise 15. Overflow goes to a **backlog** and drains back in when there is room (never during a post-kill quiet window).
- **Split:** a non-targeted, non-boss tier 2 or 3 becomes two kids of `tier - 1` if `live + 2 ≤ cap`.
- **Merge:** if live bugs exceed the cap, the two closest non-boss bugs fuse. The survivor’s tier is `min(3, max(a, b))` and it keeps some of the combined HP. Merges never create a boss.
- After an automatic kill the spawner stays quiet for **0.7s** (or **3.2s** if the board is empty) so a laser kill does not instantly hatch a replacement. Player squashes use a **1.2s** quiet if they clear the board.
- With the **Profiler**, some hatches appear as dashed “hatching” outlines for **1.2s**. Hatching bugs cannot be clicked or lasered yet.

Radii / wander speeds / HP by tier (`1…3`, boss = 4): radius `[8, 13, 19, 28]`, speed `[62, 44, 30, 22]`, HP `[2, 4.5, 8, 22]`.

### Unlock order

Only the **next** gated unlock is shown (Hire Agent stays listed after the first one so you can stack turrets). Extra **Unit Tests** ranks stay buyable (up to 5) while the next unlock is Profiler, Collision Editor, CI, or QA.

**Hire Derick → Hire Agent → Unit Tests → Profiler → Collision Editor → CI Pipeline → QA → Rapid Prototype → Agentic Workflow (requires 5 agents) → Movement Tuning → Multiplayer Sync → Sub-Agent Workflow → Rollback Netcode → Auto Rollback → Ship.**

`nextUnlock()` still returns `agentic` after Rapid Prototype so Movement Tuning and Multiplayer Sync cannot skip ahead, but the shop row itself stays hidden until you own **5 agents**. Movement Tuning (“missiles launch and fly faster”) and Multiplayer Sync (“one pulse chains to several agents”) are intentionally **after** Agentic Workflow, because that is the upgrade that makes agents leave their turrets and that starts Derick’s pulses. An upgrade never appears if it would affect something you do not have yet.

### Derick

One engineer, drawn as a green “DJ” orb, about **2.4×** the original size on desktop (`derickScale = 2.4`, body radius `6 × scale` ≈ 14.4px) and **2.0×** on coarse pointers or viewports under 700px (body ≈ 12px) so he stays readable on a tablet without eating the screen. The laser stays thin (width 1, ~0.1s). He still paints on the game canvas under page content.

- Base time to kill a small bug: **2.0s**, floored at **0.35s** after tools/ships.
- Combat DPS is `2 / killTime`, times **1.1** if CI is owned. Kill time already shortens with Ships (`× 0.88` each), CI (`× 0.82`), Profiler (`× 0.92`), and Agentic (`× 0.9`), so his stacked power on agents scales with those upgrades.
- Range: **140** desktop / **110** on coarse pointers, plus Profiler / Agentic / Ship bonuses above. In command mode the combat range is `min(range, 150)`.
- Laser color: site-accent **green** (`LASER_COLOR.derick` = `rgba(57,255,136,0.85)`).
- Roam lerp speed 120 (140 in command mode).
- Agentic Workflow is the only thing that makes him send pulses to agents (any range) and gather them into an escort. His **aura** (see Agents) buffs nearby units automatically. He **always roams** toward the biggest threat — he never parks in a corner. When nothing is on the board he eases back to the center of the play area and hovers there (a small sine bob).
- After the first prestige he is drawn as a pink beating heart (canvas Bézier, no emoji sprite) instead of the green circle. The path is left/right symmetric with roughly equal width and height (`~2s × 2s`) so it stays a round heart at every size — including mobile / coarse scale 2.0 and the `HEART_DJ_SCALE` 1.8 desktop draw. The beat pulse and canvas DPR both apply a uniform scale (no single-axis squash).
- Clicking DJ always sprays a handful of pooled, cached heart sprites. Five clicks inside **5 seconds** start a **Heartbeat** buff for **60 seconds**: DJ’s idle LOC rate is **5×**, and escorts inside his range get his **full** combat DPS aura instead of the usual 25% escort share. A pulsing pink glow and a HUD timer (`♥ 0:47`) show while it is active. After it expires there is a **60 second** cooldown so you cannot chain it. Starting Heartbeat also arms the hidden `git blame` boss (same as the Konami code).

### Agents

Hired as **static turrets** placed around the page. They fire thin lasers (width 0.9) at bugs inside their radius (**92** desktop / **78** coarse, **+22** with Profiler) and take 2 seconds to kill a small bug (base DPS **1**, times **1.08** if CI is owned).

They **do not walk** until Agentic Workflow is owned. Once it is, every agent leaves its turret post and joins an **escort ring** around Derick (slow orbit, radius `min(88, 38 + √n × 14)` on desktop, cap 72 on coarse/small screens). They fire thin lasers from the formation. A pulse no longer starts a long chase: without Sub-Agent Workflow it launches that agent as a **homing missile** (see below), and after the blast the agent recoils back to its slot in the ring. With Sub-Agent Workflow the escort itself never leaves — its orbiting sub-agent is the bomb.

**Force multiplier.** Derick is a force multiplier, not just another laser. The pulse missile is the big hit; the aura is a helper.

- **Aura (static turrets, before Agentic):** any turret inside Derick’s combat range adds his full combat DPS to its own laser (`agent DPS + Derick DPS`).
- **Aura (escorts, after Agentic):** escorts sit in that aura almost all the time, so each one only gets a modest `+ 0.25 × Derick DPS` (`ESCORT_AURA`). The ring does not clone a whole extra Derick per agent. During a **Heartbeat** buff, escorts that are actually inside Derick’s range get the full Derick DPS add instead.
- **Pulse:** the launched missile (the agent, or its sub-agent once Sub-Agent Workflow is owned) does not keep a stacked laser. The explosion *is* the force-multiplier moment, and both its radius and damage scale with Derick’s combat DPS.
- Collision Editor pierce shots still deal `0.55 ×` base agent DPS (no extra Derick add on the splash).

**Laser colors** (named constants in `LASER_COLOR`, easy to swap; red is reserved for bosses):

- Derick: green `rgba(57,255,136,0.85)`
- Agent (unbuffed): bright electric blue `rgba(62,198,255,0.92)`
- Buffed agent (aura or pulse): orange/amber `rgba(255,177,66,0.95)`, with a soft amber glow on the beam and a small amber halo on the agent

### Agentic Workflow, pulses, and command mode

- While Agentic is owned and at least one agent exists, Derick accumulates pulses at **0.35/s** (0.55/s in command mode), times `(1 + sync × 0.5)`.
- Each pulse flies to a ready escort and launches a homing missile at the current highest-value prey that is not already covered by incoming bomb damage (Ship first, then bosses, then high tier). Without Sub-Agent Workflow the escort itself launches; with it, only escorts that have an orbiting sub ready are eligible.
- **Missile flight:** starts at **220** px/s (**+50** with Movement Tuning, **+8** per Ship), accelerates at **980** px/s² up to **520** (**+90** Movement, **+16** per Ship). A **210** px/s sideways kick plus **~8 rad/s** steering makes a curved path. The aim point sits **22px** past the target (a slight overshoot). It detonates when it comes within `targetRadius + 12` px (after at least **0.08s** of flight), or after **2.4s**, or after **0.35s** with no live target.
- **Blast:** radius `min(150, base + DerickCombatDPS × 12)` where `base` is **54** on coarse/small screens and **68** on desktop — about **80px** at default power, up to **150px**. Center damage is **`3.6 × DerickCombatDPS`** (about **3.6** HP at the start: enough to delete a tier-1 and dent a tier-2), falling off to **55%** at the rim. That damage scales with Derick’s tools and ships, so he stays the force multiplier.
- **Bosses:** a single blast is capped at **35%** of the boss’s max HP (`MISSILE_BOSS_FRAC`, 7.7 of 22). A full-health boss always needs at least three missile hits. Ordinary bugs in the radius can die in one shot. The **Ship finale** is not under that cap — missiles deal full scaled damage to it (clicks still cannot kill it).
- After the explosion (without Sub-Agent Workflow) the agent recoils opposite its inbound velocity (up to **340** px/s) and lerps back to its escort slot (`dt × 6`). Sub-agents are suicide bombers: they vanish on detonation and a new sub respawns on that escort after **4 seconds**.
- **Reserved damage:** when a bomb is assigned a target it reserves its predicted center damage (`missileDamage()`, capped at 35% of max HP for regular bosses, uncapped for the Ship). Later bombs skip any target whose reserved incoming damage is already ≥ its current HP and pick the next-best prey instead. This applies to normal bugs, bosses, and the Ship.
- Juice on detonation (skipped or thinned when `prefers-reduced-motion` or quality is low): screen shake **2–5**, a small local blast flash (pooled, max 6), a milder fullscreen tint only at quality 3, **22ms** hit-stop at quality 3 (16ms otherwise), cached spark sprites instead of per-particle gradients, and an expanding blast ring.
- Agents already standing inside Derick’s range are buffed by his **aura** without needing a pulse (escorts get the modest 25% bonus; see Agents).
- Without Sync, one agent is pulsed; with Sync, up to three.
- **Command mode** turns on automatically at **10 agents**: Derick pulses faster (0.55/s) and roams a bit more snappily, and his combat range is min’d with 150 (overall range capped at 160). He does **not** park.

### QA

QA does **not** squash bugs for you.

- It **reveals** extra bugs at **0.55/s** (× **1.6** if CI is owned), flashing them in as they appear. Reveals respect the same cap and post-kill quiet window as other automatic spawns.
- It **paints a target** on the largest live bugs (tier ≥ 3 or bosses), up to `1 + qa` marks (so 2 once QA is bought). Targeted bugs **die without splitting** and pay **1.25×** commits, whether you click them or a laser finishes them.

### Bosses

Named: **Desync**, **Memory Leak**, **Race Condition**, **Null Pointer**, **Frame Spike**, **Packet Loss**, **Rollback Ghost**, **Stale Snapshot**.

- A new boss never reuses the **immediately previous** boss name. The last name is stored on the save as `lastBoss` and is skipped when picking the next one (the other seven names remain in the pool).
- They only start appearing after Hire Derick. Chance accumulates at `0.015 + min(0.04, loc/50000)` per second, and never during a quiet window or when the board is already at cap.
- Tier 4, 22 HP, 28px radius, red ring plus an HP bar and name.
- **Clicks cannot kill them.** A click “clinks,” knocks them back, and chips at most **0.05** HP without ever dropping them below **1**. Derick or an agent has to finish the job. QA can mark them so the kill does not split (bosses do not split anyway).
- After prestige, live-ops / “2.0” boss names unlock **two per prestige level** and are added to the regular pool (still skipping the immediately previous name):

  1. Prestige 1: **Day-One Patch**, **Server Queue**
  2. Prestige 2: **Desync Storm**, **Shader Compile Stutter**
  3. Prestige 3: **Crunch Time**, **Cert Failure**
  4. Prestige 4+: **Save Corruption**, **Loot Box Backlash**

  A hidden **git blame** boss can appear (about 8% after prestige 1, or 35% once you have armed it via the Konami code or a Heartbeat proc).

### Ship finale and prestige

Clicking **Ship vN.0** (once you have the LOC goal and ≤ 3 bugs) force-switches into Play Space and starts a finale rather than instantly incrementing a counter.

- A giant ship enters from the top at full play-area width, with a warning banner, screen shake, and a named HP bar at the bottom center (`Ship v1.0`, then `v2.0`, …).
- The **7 teal dots** along the top band are individually targetable **hardpoints**. Each node gets an equal share of the ship’s HP; the bottom bar shows the **sum**. The ship dies only when every node is destroyed.
- Lasers and bombs pick among live nodes: they prefer the least-targeted / nearest node and respect the same reserved-damage dedupe per node (a bomb will not stack onto a hardpoint that incoming bombs would already kill). Anyone who could reach the hull can still fire, but they aim at a node so the beams spread out instead of converging on the center.
- Destroying a node is juiced (flash, sparks, “DOWN”) and the node goes dark/cracked. Regular bugs (~every 0.55s when all 7 are up) and named bosses (~every 6.2s) spawn **from live nodes only**, so the drop rate relaxes as hardpoints fall (interval scales by `7 / liveNodes`).
- **Only lasers and missiles damage nodes.** Clicks clink (hull or node) just like a normal boss and cannot finish a hardpoint.
- Its max HP is `max(500, estimatedDPS × 106)` (the 106× multiplier is calibrated so a full-unlocks / 10-agent team takes about **90 seconds**, ±15s).
- On a win: a juiced “SHIPPED” beat, then a **prestige** reset. Run progress (tools, agents, LOC, commits, live bugs) clears; Derick stays hired, the shop stays open, Play Space stays unlocked, and `prestige` / `ships` increment together. The next Ship goal scales up. DJ becomes a pink beating heart.
- Prestige persists on the `dj-bughunt-v3` save. Older saves that already have `ships` but no `prestige` migrate `prestige = ships`.

**Small prestige extras**

1. Pink beating-heart DJ at `prestige >= 1` (symmetric round Bézier heart).
2. HUD title becomes `BUG HUNT vN.0`.
3. Konami (`↑↑↓↓←→←→BA`) launches an extra missile volley (no `preventDefault`) and arms `git blame`.
4. Clicking DJ sprays pooled hearts; five clicks in 5s starts a 60s **Heartbeat** buff (5× DJ LOC, full aura on nearby escorts, pink glow + HUD timer, 60s cooldown) and arms `git blame`.
5. Progressive live-ops boss names listed above, plus the hidden **git blame** boss.

### Idle behavior and away-from-tab

Idle drafting is **per-unit**, not global. Derick and each agent write code independently whenever *that* unit has no target in range / is not lasering — even if bugs exist elsewhere on the page. There is no “wait until the board has been clear for 3 seconds.”

- Derick drafts at **1.4** LOC/s (`IDLE_DERRICK`), plus **0.60** if Agentic Workflow is owned (`IDLE_AGENTIC`).
- Each agent drafts at **0.35** LOC/s (`IDLE_AGENT`) — about 5× the original rates. During Heartbeat, Derick’s own rate (including the Agentic bonus) is multiplied by **5**.
- Orbiting sub-agents (once Sub-Agent Workflow is owned) also draft at **0.35** LOC/s until they launch.
- A unit counts as idle when it is **not firing**. Outbound missiles count as firing; a missile on its way back to the ring can draft again. Escorts that happen to be lasering a bug in range still count as busy (correct), even if they are standing near Derick.
- After a unit stops attacking, idle drafting ramps in within **0.5s** (the accumulator is seeded to `1 - rate × 0.5` so the first line lands quickly instead of waiting a full `1/rate` seconds).
- A tiny `{}` tick appears near the unit when it drafts (cheap visual cue).
- Each drafted line adds only `bugsPerLoc() × 0.045` debt (`IDLE_DEBT`), and hatches still respect the post-kill quiet window, so the faster idle typing does not instantly refill the board.

If you leave and come back still opted-in and unpaused, up to **900s** of absence is estimated: a capped number of auto-kills and commit payout, logged when you were away more than 20 seconds. Pause and quit both save and stop the loops.

- An unused/empty v3 slot will import `dj-bughunt-v2` (`cash` becomes `commits`, `ai` becomes `agents`, a few v2 flags become 0-or-1 ranks). The old `dj-bughunt-v1` key is removed.
- `lastBoss` (the previous boss name) is persisted so a reload cannot immediately repeat it.
- `clicks`, `playUnlocked`, and `playSpace` remember Play Space progress and whether you are in that mode. Quitting from Play Space writes `playSpace: false` so a later resume stays on the site.
- `prestige` (and `ships`, kept in sync) remember how many finales you have shipped. A v3 save that has `ships` but no `prestige` is migrated on load.
- Up to 20 live bugs are stored as normalized positions plus tier/HP/boss/name. The save writes every 2 seconds while playing, on pause/quit/hide, and on `bh-save` (used before in-site navigations).
- **Reset progress** (and `__bugHunt.reset()`) confirms, then clears `dj-bughunt-v3` **and** any leftover `v1`/`v2` keys, wipes in-memory state, and sets a flag so the pagehide / visibilitychange / 2s-interval savers cannot write the old run back before reload. That last step is what made Reset appear to do nothing on phones.

### Performance tiers

Quality starts at **3**, or **1** if `prefers-reduced-motion` is on. The last ~45 frame times are watched:

- Average frame **> 21ms** for several samples → step quality down.
- Average **< 13.5ms** for longer → step back up (not above 1 when reduced-motion is on).

Lower quality cuts particle counts, screen shake, and device-pixel ratio (caps: 2 / 1.5 / 1 / 0.7). Particles are pooled (`partN`, caps 140 / 70 / 28) and drawn from cached radial sprites (no per-particle `hsl()` or `createRadialGradient`, and no `shadowBlur` on sparks). DJ heart bursts use a second pooled sprite (`heartN`, caps 36 / 18 / 8) drawn with `drawImage`. Local explosion flashes are capped at 6; the old full-screen fill is a light tint and only at quality ≥ 2. Hit-stop is capped at 26ms (quality 3) / 16ms otherwise so the sim does not freeze-walk for long. Profiler range rings are batched into one faint stroke (`rgba(62,198,255,0.08)`) and skipped entirely below quality 2. Reduced motion also disables the hero glitch and most juice.

### Layering and input

- Background code canvas is `z-index: 0`. Bug canvas is `z-index: 1`. Page `main` is `z-index: 2`, so bugs crawl **under** cards, type, and links.
- Both canvases use `pointer-events: none`. The game listens on the document and **never calls `preventDefault`**.
- Clicks on links, buttons, inputs, media, the HUD, or the Play button are ignored by the game (the page handles them). Drags, long-presses, and text selections are ignored too.
- On empty space: click a bug to squash it (or clink a boss); otherwise write +1 LOC. Touch slop is 20px, mouse slop is 12px.

HUD: **❚❚** pause (keeps Play Space if you are in it), **⟲** rollback (once unlocked), **Play Space** / **Site** (once unlocked), **–** minimize, **✕** quit (keeps progress, and leaves Play Space so the site comes back).

### Design rules from Derick

These are the explicit asks the implementation is meant to honor:

1. Players opt in (Play Bug Hunt); the game does not start itself.
2. Progress is remembered if they leave and come back.
3. No bugs on screen until they click empty space.
4. Clicks write dim hacker-typer background code.
5. The first unlock is **Hire Derick**.
6. QA reveals bugs and paints targets on the largest; targeted bugs are destroyed instead of breaking into smaller ones. QA does not auto-squash.
7. Agentic Workflow amplifies Derick’s lasers (faster kill, longer range), gathers agents into an escort around him, and is the thing that launches them as homing missiles.
8. Bugs render under page elements. The canvas never steals clicks from real UI; clicking a bug in empty space never navigates.
9. Agentic Workflow is gated behind a chain of earlier upgrades, and also requires owning 5 agents, not handed out with the first agents.
10. An upgrade that affects pulses or missiles (Movement Tuning, Multiplayer Sync) cannot appear before Agentic Workflow (the thing that actually launches missiles).
11. Excess bugs merge, and animation quality steps down if frames get slow.
12. Long sessions must not leak memory or gradually hitch.
13. Once opted in with staff hired, idle Derick/agents write LOC when they are not firing (per-unit, including a short ramp after they stop attacking).
14. Bosses cannot be click-killed.
15. All game code is original to this project — not copied from another site’s clicker.
16. Derick always roams toward threats. He never parks in a corner, even in command mode.
17. Pulses are juiced homing missiles with an AoE blast (bosses don’t get one-shot). After the boom the agent returns to the escort ring — unless Sub-Agent Workflow is owned, in which case the sub-agent is the bomb and the escort stays put.
18. After 25 player clicks the game can promote into Play Space: a full-screen playfield with Derick’s name visible but not clickable, plus a way back to the site.
19. ✕ while in Play Space exits Play Space (chrome + scroll restored) and saves; pause does not. Resume only re-enters Play Space if it was still marked active.
20. Ship is a juiced finale boss, not a one-click counter. Its seven hardpoint nodes share its HP and are what lasers and bombs actually hit; winning prestiges the run and DJ becomes a pink beating heart.
21. Clicking DJ sprays hearts; five clicks in 5 seconds starts a cooldown-gated Heartbeat buff.
22. Sub-Agent Workflow (after Agentic + Multiplayer Sync) replaces escort missiles with orbiting, code-writing suicide bombers that refuse overkill targets.


## Deploying

### GitHub Pages (recommended, free)
1. Create a repo (e.g. `zorakbane/derickjanssen.com`) and push this folder to `main`.
2. Repo **Settings → Pages → Source: GitHub Actions**. The included `.github/workflows/pages.yml` builds and deploys on every push.
3. **Settings → Pages → Custom domain:** `www.derickjanssen.com`, then tick **Enforce HTTPS** once the certificate is issued. `static/CNAME` already contains `www.derickjanssen.com`.

### Netlify / Vercel
Import the repo. `netlify.toml` / `vercel.json` already set build `node build.mjs --hide-todos` and output `dist`. Then add the custom domain in their dashboard and follow the DNS values they show.

### Sub-path hosting
If the site lives at `https://user.github.io/repo/` without a custom domain, build with `BASE=/repo/ node build.mjs`. In the workflow, change the build step to `BASE=/repo/ node build.mjs --hide-todos`.

## Pointing the GoDaddy domain (GitHub Pages)

In GoDaddy → **My Products → derickjanssen.com → DNS → Manage DNS**:

1. **Remove** the existing `www` CNAME that points to Google Sites (`ghs.googlehosted.com`) and any `@` A records for Google or GoDaddy parking/forwarding.
2. Add **CNAME** `www` → `zorakbane.github.io` (your GitHub username + `.github.io`).
3. Add four **A** records for `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`. Optionally add the AAAA records `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, and `2606:50c0:8003::153`.
4. Wait for DNS (minutes to a few hours). Then set the custom domain in GitHub Pages settings and enable HTTPS.
5. Optional but recommended: verify the domain under GitHub **Settings → Pages → Verified domains** so nobody else can claim it.

For Netlify/Vercel, use the records their dashboards give you instead (usually a `www` CNAME plus an apex A/ALIAS record).

## Performance notes
- CSS is inlined, JS is ~25 KB unminified and deferred, and the game loads on idle.
- Images are resized WebP with `srcset`, lazy-loaded, and have width/height set (no layout shift). YouTube uses a click-to-load facade on `youtube-nocookie.com`.
- Page transitions use the cross-document View Transitions API (`@view-transition`). Other browsers get a quick wipe fallback.
- Lighthouse mobile v1 (local, uncompressed server): Performance 97–99, Accessibility 96+, Best Practices 100, SEO 100.
